# Token Portrait Prompt Template (Cohesive Visual Style)

```text
Top-down fantasy RPG token portrait of {SUBJECT}, {appearance: ancestry, age, defining features, attire, weapons/gear}.
Painterly digital illustration, rich colors, dramatic soft lighting, chest-up three-quarter view,
character centered and filling the frame, plain dark muted background, high detail, readable at small size.
No text, no watermark, no border, no frame.
```

Optional modifiers:
- **Large / Huge creature:** `"full-body, dynamic pose, seen from above at 45 degrees"`
- **Swarm / pack:** `"cluster of {N} {creatures}, token style"`
- **Setting flavor:** Add 5–8 words matching the tone of `{{CAMPAIGN_NAME}}` (e.g., `"gritty medieval dark fantasy atmosphere, muted earthy palette"`).

> Always append the default style suffix from `.agents/rules/art-style.md` so every token across the vault looks cohesive on the VTT canvas.
