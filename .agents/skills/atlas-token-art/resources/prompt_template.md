# Template Prompt per Token (Stile Coerente)

```text
Top-down fantasy RPG token portrait of {SOGGETTO}, {aspetto: specie, età, tratti distintivi, abiti, equipaggiamento}.
Painterly digital illustration, rich colors, dramatic soft lighting, chest-up three-quarter view,
character centered and filling the frame, plain dark muted background, high detail, readable at small size.
No text, no watermark, no border, no frame.
```

Varianti opzionali:
- **Creatura grande:** `"full-body, dynamic pose, seen from above at 45 degrees"`
- **Gruppo / sciame:** `"cluster of {N} {creature}, token style"`
- **Tono ambientazione:** aggiungi 5–8 parole coerenti con il tono di `{{CAMPAIGN_NAME}}` (es. `"gritty low-fantasy medieval atmosphere, earthy muted palette"`).

> Accoda sempre il suffisso stilistico di `.agents/rules/art-style.md` per uniformità visiva tra tutti i token della campagna.
